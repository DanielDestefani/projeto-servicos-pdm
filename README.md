# Projeto Serviços PDM

Projeto acadêmico desenvolvido para o trabalho da matéria "Programação para dispositivos móveis" do curso de Engenharia de Software da Unifatecie


## Sobre o projeto

O aplicativo é uma plataforma digital que funciona como um balcão de serviços rápido e sob demanda. A ideia central é intermediar o contato entre pessoas que têm tarefas a serem feitas e pessoas que desejam ser pagas para fazer essas tarefas


## Tecnologios usadas

- Android SDK
- Java
- Git & Github


## Como rodar o projeto

1. Clonar o repositório

```bash
    git clone https://github.com/DanielDestefani/projeto-servicos-pdm.git
```

2. Abrir o projeto no **Android Studio** ('open' -> selecionar a pasta clonada)

3. Rode um emulador ou dispositivo físico com deputação USB ativada
